# Registro de decisões

## D001 — Método principal
**Status:** congelada
DM-NeRF permanece o método principal. Baselines são termos de comparação, não substitutos do método.

## D002 — Dataset
**Status:** provisoriamente congelada
DM-SR é o dataset principal porque é oficialmente suportado pelo DM-NeRF e foi usado na prova de conceito. Replica é opcional se a execução for direta. ScanNet só entra se não ameaçar prazo.

## D003 — CAD retrieval
**Status:** removido do escopo.

## D004 — SDFormat
**Status:** detalhe de implementação.
Deve ser descrito, mas não vendido como contribuição científica.

## D005 — Gazebo
**Status:** Gazebo Classic pode ser mantido.

## D006 — Avaliação
A dissertação deve separar, quando os dados permitirem: qualidade visual, qualidade geométrica, decomposição/instâncias, efeito do pós-processamento, custo computacional e uso no simulador.

## D007 — Prazo
Planejamento usa 21/10/2026 como prazo operacional de texto. Desenvolvimento novo deve encerrar vários dias antes.
